## 🌟 نظرة عامة (Overview)

أثناء بناء المواقع وتطبيقات الويب، يحتاج المطورون لمعاينة تجربة المستخدم الحقيقية على الهواتف دون الحاجة لفتح المتصفح المكتبي وتغيير أبعاده يدوياً. يوفر **Mobile Emulator** إطاراً عائماً، خفيفاً، ودقيق الأبعاد يحاكي شاشات الهواتف والأجهزة اللوحية الشهيرة، مع شريط حالة حي، ودعم اللمس والسحب، ومحاكاة دقيقة لقطع الكاميرات والجزر الديناميكية.

## ✨ المميزات الرئيسية (Key Features)

### 1. 📱 أطر حقيقية تحاكي أبعاد الهواتف
- محاكاة دقيقة لمقاسات الشاشات ونسب العرض إلى الارتفاع وانحناءات الحواف (Border Radius).
- إمكانية تحريك نافذة الجوال بحرية وسلاسة على سطح المكتب عبر سحب الإطار الخارجي.

### 2. 🏝️ محاكاة ذكية للقطع والكاميرا (Device Cutouts)
- **Dynamic Island**: جزيرة تفاعلية أنيقة لهواتف iPhone 15 Pro / Max.
- **Punch-Hole**: ثقب كاميرا دائري صغير واقعي لهواتف Samsung Galaxy و Google Pixel.
- **None**: شاشات كلاسيكية مستطيلة بدون أي قطع داخل الشاشة لهواتف iPhone SE والأجهزة اللوحية (iPad).

### 3. 🔀 وضعان لعرض الشاشة وموضع الجزيرة
- **وضع "إلى الجزيرة" (الوضع الآمن - Safe Mode)**: يبدأ محتوى الموقع أسفل الكاميرا وشريط الحالة لضمان عدم حجب أي شعار أو زر أو قائمة في موقعك.
- **وضع "من ضمن الجزيرة" (شاشة كاملة - Fullscreen PWA)**: تمتد شاشة الموقع إلى حافة الهاتف العليا خلف الكاميرا، وهي مثالية لاختبار الـ Safe Areas وتطبيقات الويب التقدمية (PWA).
- زر تبديل فوري (`📱`) في الشريط الجانبي للتنقل بين الوضعين بنقرة واحدة.

### 4. 👆 تجربة لمس واقعية (Touch Drag-to-Scroll)
- **إخفاء شريط التمرير المكتبي**: تم منع شريط التمرير العريض المزعج الخاص بالويندوز، ليعرض الموقع بكامل عرضه المخصص للموبايل.
- **التمرير بالسحب بالماوس**: انقر في أي مكان بالشاشة واسحب للأعلى أو للأسفل لتصفح الموقع بسلاسة تامة كأنك تلمس شاشة هاتف حقيقي بإصبعك، مع بقاء عجلة الماوس تعمل كالمعتاد.

### 5. ⏱️ شريط حالة واقعي (Status Bar & Home Indicator)
- ساعة حية تتحدث تلقائياً حسب توقيت جهازك.
- مؤشرات الشبكة والـ 5G، والواي فاي، ونسبة البطارية.
- مؤشر الإيماءات السفلي (Home Bar) للهواتف الحديثة.

### 6. 🌐 دعم فتح الروابط الخارجية والمنافذ المحلية (URLs & Ports)
- **تعرف ذكي وفوري**:
  - كتابة رقم المنفذ (مثل `3000` أو `:5173`) -> يفتح `http://localhost:3000`.
  - كتابة نطاق أو موقع خارجي (مثل `google.com` أو `mysite.vercel.app`) -> يضيف له تلقائياً بروتوكول `https://` الآمن.
  - إمكانية فتح أي رابط كامل (`https://...`).
- فتح عدة مواقع ومنافذ في آنٍ واحد مع إمكانية التبديل السريع بينها عبر التبويبات.
- شاشة تنبيه ذكية توضح الأخطاء في حال انقطاع الاتصال أو إغلاق السيرفر مع زر "إعادة المحاولة".

### 7. 📸 لقطة شاشة بنقرة واحدة ونسخ مباشر للحافظة (Clipboard Screenshot)
- زر مخصص (**📸**) في الشريط الجانبي يلتقط شاشة الجوال فوراً بأعلى دقة.
- **نسخ فوري للحافظة (Clipboard)**: يتم نسخ الصورة مباشرة إلى الذاكرة دون الحاجة لحفظ ملفات، بحيث يمكنك لصقها فوراً بـ `Ctrl + V` في واتساب، تيليجرام، فيجما، أو محادثات العمل.
- تأثير وميض كاميرا واقعي (Camera Shutter Flash) مع إشعار تأكيد لطيف.
- يدعم الاختصار السريع: `Ctrl + P` أو `Ctrl + Shift + S`.

### 8. 🧭 محاكاة أجهزة وحساسات الجوال (Sensors & Hardware Emulation)
- 📍 **محاكاة الموقع الجغرافي (GPS)**: دعم كامل لـ `navigator.geolocation` مع إمكانية اختيار مدن شهيرة (الرياض، صنعاء، دبي، القاهرة، مكة المكرمة...) من قائمة الإعدادات لفحص تطبيقات الخرائط والتوصيل.
- 📷 **محاكاة الكاميرا والميكروفون (Media Stream)**: تفعيل تلقائي لتدفق فيديو كاميرا تجريبي لفحص ميزات مسح الـ QR Code ورفع الصور دون الحاجة لكاميرا حقيقية.
- 📶 **محاكاة شبكة الجوال (5G / 4G)**: محاكاة `navigator.connection` لتعريف المواقع بأن الاتصال عبر شبكة هاتف خلوي.
- 📳 **محاكاة الاهتزاز (Vibration API)** وتصاريح الجوال التلقائية دون نوافذ إذن مزعجة.

### 9. 🛠️ شريط أدوات مدمج وسهل الوصول
- 📸 **لقطة شاشة**: نسخ فوري للشاشة إلى الحافظة.
- ‹ › **أزرار الرجوع والتقدم**: تنقل سلس بين صفحات المواقع كأي متصفح حقيقي.
- 📌 **تثبيت فوق النوافذ (Always on Top)**: لإبقاء المحاكي بجانب محررك البرمجي طوال وقت العمل.
- ⤾ **تدوير الشاشة**: التبديل الفوري بين الوضع العمودي (Portrait) والأفقي (Landscape).
- ⚙️ **أدوات المطور (Chrome DevTools)**: فحص عناصر الصفحة ومراقبة الـ Console و Network بنقرة زر.
- ↗️ **فتح في المتصفح الخارجي**: فتح الرابط الحالي في متصفحك الافتراضي.
- ⟳ **تحديث سريع (Reload)**: إعادة تحميل الصفحة الحالية بنقرة واحدة أو عبر `F5`.

## 🚀 طريقة التثبيت والتشغيل للمطورين (For Developers)

### المتطلبات الأساسية
- تأكد من تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث).
- مدير الحزم `npm`.

### خطوات التثبيت والتشغيل المحلي:

1. **استنساخ المستودع (Clone):**
   ```bash
   git clone https://github.com/fanalelan-oss/Mobile-Emulator.git
   cd Mobile-Emulator
   ```

2. **تثبيت الحزم (Install Dependencies):**
   ```bash
   npm install
   ```

3. **تشغيل المحاكي في وضع التطوير (Start):**
   ```bash
   npm start
   ```

4. **بناء النسخة التنفيذية للويندوز (Build Installer):**
   ```bash
   npm run dist
   ```
   سيتم إنشاء ملف التثبيت بصيغة `exe` داخل مجلد `dist/`.
